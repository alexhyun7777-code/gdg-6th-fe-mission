# Mission 01. API 통신 맛보기

## 1. API란?

API는 프론트엔드와 백엔드가 데이터를 주고받기 위한 약속이다.  
프론트엔드는 화면을 보여주는 역할을 하고, 백엔드는 필요한 데이터를 보내주는 역할을 한다.

예를 들어 상품 목록, 게시글 목록, 사용자 정보 같은 데이터는 백엔드에서 받아오고, 프론트엔드는 그 데이터를 화면에 표시한다.

---

## 2. API 통신이 필요한 이유

HTML, CSS, JS만으로는 고정된 화면은 만들 수 있지만, 실제 서비스처럼 계속 바뀌는 데이터를 보여주기 어렵다.

API를 사용하면 서버에서 데이터를 받아와서 화면에 반영할 수 있다.

예시:

- 게시글 목록 불러오기
- 상품 정보 불러오기
- 로그인한 사용자 정보 가져오기
- 댓글 작성 후 서버에 저장하기

## 3. fetch 함수

`fetch`는 JavaScript에서 API 요청을 보낼 때 사용할 수 있는 내장 함수이다.

```js
fetch("API 주소")
  .then((response) => response.json())
  .then((data) => {
    console.log(data);
  });

4. 비동기 처리

API 요청은 시간이 걸리는 작업이다.
서버에 요청을 보내고 응답을 받을 때까지 기다려야 하기 때문이다.

이때 JavaScript는 요청이 끝날 때까지 전체 코드를 멈추지 않고, 다른 코드를 먼저 실행한다.
이런 방식을 비동기 처리라고 한다.

비동기 처리를 제대로 하지 않으면 데이터가 아직 오기 전에 화면을 그리려고 해서 오류가 생길 수 있다.

5. async / await

async / await을 사용하면 비동기 코드를 더 읽기 쉽게 작성할 수 있다.

async function getData() {
  const response = await fetch("API 주소");
  const data = await response.json();

  console.log(data);
}

await은 해당 작업이 끝날 때까지 기다린 뒤 다음 줄을 실행하게 해준다.
그래서 API 데이터를 받아온 뒤 화면에 출력하는 흐름을 더 직관적으로 작성할 수 있다.

6. API 데이터를 화면에 보여주는 흐름

API 통신을 통해 데이터를 화면에 보여주는 기본 흐름은 다음과 같다.

API 주소로 요청을 보낸다.
서버에서 응답을 받는다.
응답 데이터를 JSON 형태로 변환한다.
필요한 데이터를 꺼낸다.
HTML 또는 React 화면에 표시한다.
