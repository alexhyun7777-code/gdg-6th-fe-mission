# 1주차 학습 일지
이번 1주차 스터디에서는 HTML의 기본 구조와 웹페이지를 구성하는 핵심 태그들에 대해 학습하였다. 먼저 h1, h2와 같은 제목 태그를 통해 문서의 구조를 나누는 방법을 이해하였고, p 태그를 사용하여 문단을 구성하는 방법을 익혔다. 또한 a 태그를 활용하여 서로 다른 HTML 파일을 연결하는 하이퍼링크 기능을 직접 구현해보았다. 이를 통해 하나의 페이지가 아닌 여러 페이지로 구성된 웹사이트의 기본 원리를 이해할 수 있었다. 더불어 script 태그를 사용하여 console.log와 alert를 실행해보며 자바스크립트의 기본적인 동작도 경험하였다. 이번 학습을 통해 웹페이지의 기본적인 구조와 페이지 간 연결 방식에 대해 전반적으로 이해할 수 있었으며, 앞으로 더 다양한 기능을 추가할 수 있는 기초를 다질 수 있었다. 다음 과제에서는 선택사항도 다 수행해보려는 능력을 길러야 겠다.
#  2주차 학습일지
이번 주에는 JavaScript를 활용하여 간단한 카운터 앱을 직접 구현해보았다.  
HTML에서 버튼과 숫자를 표시할 요소를 가져오기 위해 getElementById()를 사용하였고, 이를 통해 DOM 요소를 JavaScript에서 제어할 수 있다는 점을 이해할 수 있었다.  

또한 addEventListener()를 이용하여 버튼 클릭 이벤트를 처리하는 방법을 학습하였다. 각 버튼에 클릭 이벤트를 연결하고, 해당 이벤트가 발생했을 때 특정 함수가 실행되도록 구현하면서 이벤트 기반 프로그래밍의 기본 구조를 익힐 수 있었다.  

count라는 변수를 선언하여 현재 숫자를 저장하고, 이를 기반으로 +1, -1, reset 기능을 구현하였다. 버튼을 누를 때마다 변수 값이 변경되고, 변경된 값을 textContent를 통해 화면에 다시 출력하는 과정을 통해 데이터와 화면이 연결되는 흐름을 이해하게 되었다.  

추가적으로 +10, -10 버튼을 구현하면서 +=, -=와 같은 복합 대입 연산자의 사용법도 익혔고, 단순한 증가/감소를 넘어서 다양한 연산을 적용할 수 있다는 점을 확인하였다.  

이번 과제를 통해 JavaScript의 기본적인 문법인 변수 선언, 함수 정의, 연산자 활용뿐만 아니라, DOM 조작과 이벤트 처리 방식에 대해 전반적으로 이해할 수 있었다. 특히 사용자의 입력(클릭)에 따라 화면이 동적으로 변화하는 과정을 직접 구현해보면서, 웹 페이지가 단순한 정적인 문서가 아니라 상호작용이 가능한 구조라는 점을 체감할 수 있었다.  

앞으로는 조건문이나 반복문과 같은 문법을 함께 활용하여 더 다양한 기능을 가진 웹 애플리케이션을 만들어보고 싶다.
