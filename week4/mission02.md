# ESLint & Prettier

## ESLint란?

ESLint는 JavaScript와 React 코드에서 발생할 수 있는 문제를 찾아주는 정적 분석 도구이다.

코드를 실행하기 전에 잠재적인 오류를 발견할 수 있으며 사용하지 않는 변수나 정의되지 않은 변수 등을 검사할 수 있다.

ESLint를 사용하는 이유는 다음과 같다.

- 잠재적인 오류 발견
- 코드 품질 향상
- 일관된 코딩 규칙 적용
- 협업 시 코드 관리 용이



## Prettier란?

Prettier는 코드 스타일을 자동으로 정리해주는 포맷팅 도구이다.

들여쓰기, 따옴표, 세미콜론, 줄바꿈 등을 일정한 규칙에 맞게 자동으로 수정해준다.

Prettier를 사용하면 팀원마다 다른 코딩 스타일을 통일할 수 있으며 코드의 가독성을 높일 수 있다.



## ESLint와 Prettier의 차이

ESLint는 코드의 오류를 검사하는 역할을 담당한다.

반면 Prettier는 코드의 형식을 정리하는 역할을 담당한다.

즉,

- ESLint : 코드에 문제가 있는지 검사
- Prettier : 코드를 보기 좋게 정리

라고 이해할 수 있다.



## 쇼핑몰 프로젝트 적용

이번 주차에는 쇼핑몰 프로젝트에 ESLint와 Prettier를 적용해보았다.

ESLint를 실행한 결과 사용하지 않는 변수와 정의되지 않은 변수를 발견할 수 있었다.

또한 Prettier를 적용하여 따옴표, 세미콜론, 줄바꿈 등의 스타일을 일관되게 정리할 수 있었다.

코드는 정상적으로 실행되더라도 ESLint를 통해 잠재적인 문제를 미리 발견할 수 있다는 점을 확인하였다.
