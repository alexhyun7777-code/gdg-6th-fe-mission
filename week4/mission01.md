# Refactoring & Custom Hook

## 리팩토링(Refactoring)

리팩토링은 프로그램의 기능은 그대로 유지하면서 코드의 구조를 개선하는 작업이다.

프로젝트 규모가 커질수록 하나의 파일에 많은 코드가 작성되거나 비슷한 코드가 여러 곳에 반복될 수 있다. 이러한 상황에서는 유지보수가 어려워지기 때문에 코드를 역할에 맞게 분리하는 과정이 필요하다.

React에서는 보통 페이지를 담당하는 컴포넌트와 재사용 가능한 컴포넌트를 구분하여 관리한다.

- Pages : 페이지 단위 컴포넌트
- Components : 재사용 가능한 UI 컴포넌트

이처럼 관심사를 분리하면 코드의 가독성이 높아지고 수정이 쉬워진다.



## Custom Hook

Custom Hook은 여러 컴포넌트에서 반복적으로 사용하는 로직을 하나의 Hook으로 분리하여 재사용하는 방법이다.

React에서는 useState, useEffect 등의 Hook을 제공하는데, 동일한 상태 관리 로직이나 이벤트 처리 로직이 반복된다면 Custom Hook으로 관리할 수 있다.

Custom Hook을 사용하면 다음과 같은 장점이 있다.

- 중복 코드 감소
- 재사용성 향상
- 가독성 향상
- 유지보수 용이

컴포넌트는 화면을 담당하고 Custom Hook은 로직을 담당하도록 역할을 나눌 수 있다.
